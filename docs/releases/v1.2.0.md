## More references. Same uninterrupted workspace.

OnTop now gives **every shared window its own live, click-through preview**. Keep a diagram and documentation visible together, and arrange each one exactly where you need it.

### What's new

- **Add Window…** adds another reference without replacing the existing preview. Add one window at a time with the macOS picker; both remain shared.
- Independent position, proportional size, **30–100% opacity**, Return to App, source replacement, and Stop for every window.
- Per-window menu actions and **Stop All**. New previews start in separate positions and remember their settings by slot.
- Switching to a source app hides that app's previews; references from other apps remain visible.
- Overlapping previews show the topmost window's hover controls. Stopping one stream leaves the others running.
- Duplicate-source detection on macOS 15.2+, late-callback protection, and native multi-window regression coverage.

### Install

Download **OnTop-1.2.0-universal.dmg**, open it, and drag **OnTop** into **Applications**, replacing the old version. Quit a running OnTop first. A ZIP is also available; both support Apple Silicon and Intel.

macOS **14+** is required. Return to App, automatic source-app hide/restore, and duplicate-source detection require **15.2+**.

Current installers are **ad-hoc signed, not Apple-notarized**. If blocked on first launch, use **System Settings → Privacy & Security → Open Anyway** after attempting to open the app. [Apple's instructions](https://support.apple.com/en-us/102445).

`SHA256SUMS` contains the download checksums. Build provenance is also available:

```bash
gh attestation verify OnTop-1.2.0-universal.dmg --repo laixintao/ontop
```

## 多份参考资料，各有自己的浮窗

现在，**每个共享窗口都有独立的实时穿透预览**。可以同时看图表和文档，自由摆放各自的位置。

- 菜单栏 **添加窗口…** 会新增预览，不再替换已有窗口。在系统选择器中逐个添加，两个来源可以同时保持共享。
- 每个窗口独立移动、等比例缩放、设置 **30%–100% 不透明度**、返回 App、更换来源和停止。
- 各窗口独立菜单，以及 **全部停止**；新浮窗错开排列，按槽位分别记住设置。
- 切回来源 App 时只隐藏该 App 的预览，其他参考窗口继续显示。
- 重叠时仅显示最上方预览的悬停控件，停止一个来源不影响其他采集。
- macOS 15.2+ 支持重复来源去重，增加迟到回调防护和多窗口原生回归测试。

下载通用 DMG，先退出旧版 OnTop，再拖入「应用程序」替换安装；也提供 ZIP。支持 Apple Silicon 和 Intel，要求 macOS 14+。返回、自动显隐和去重要求 macOS 15.2+。

**当前未经过 Apple 公证**。首次打开如被拦截，先尝试打开，再前往「系统设置 → 隐私与安全性 → 仍要打开」。[Apple 的说明](https://support.apple.com/zh-cn/102445)。附件提供 SHA-256 校验文件和 GitHub 构建来源证明。
