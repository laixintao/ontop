## Smooth native dragging

Fix the preview lagging behind the pointer while dragging. OnTop now lets macOS move the picture, toolbar, and resize handle together. The large grip, click-through picture, external hover controls, and independent opacity stay available.

- Finish and save a drag even when macOS consumes the mouse-up event.
- Prevent position jumps when resizing immediately after dragging, including rapid successive gestures.
- Clean up the moving group when hiding, returning to the source app, stopping, resetting, or replacing a source. Apply source-size and display changes after release.
- Add native regression coverage for grouped click-through, independent previews, gesture completion, immediate resizing, display placement, and interrupted dragging. Hands-on testing confirmed smooth dragging and no resize jumps.

Quit OnTop before updating. With Homebrew:

```sh
brew update
brew upgrade --cask laixintao/tap/ontop
```

Or download **OnTop-1.3.2-universal.dmg** and drag OnTop into Applications. ZIP is also available. Both support Apple Silicon and Intel. Requires macOS 14+; Return to App and automatic source-app hiding require macOS 15.2+.

Builds are ad-hoc signed and not Apple-notarized. See the [installation instructions](https://github.com/laixintao/ontop#install). Downloads include `SHA256SUMS` and GitHub build provenance:

```sh
gh attestation verify OnTop-1.3.2-universal.dmg --repo laixintao/ontop
```

## 拖动恢复流畅

修复拖动浮窗时跟不上鼠标的问题。现在由 macOS 整体移动图片、控制条和缩放手柄，保留大手柄、画面穿透、外置悬停控件和独立透明度设置。

- 即使 macOS 消耗鼠标松开事件，也能正常结束拖动并保存位置。
- 修复拖动后立即缩放时的位置跳动，支持快速连续操作。
- 隐藏、返回来源 App、停止、重置或更换来源时正确解除窗口组合；松开后应用来源尺寸和显示器变化。
- 补充组合状态下的点击穿透、多预览隔离、拖动结束、立即缩放、跨屏落点和中断清理测试。实测确认拖动流畅、缩放无跳动。

先退出旧版，再运行上面的 Homebrew 升级命令，或下载安装包拖入「应用程序」替换。DMG / ZIP 均支持 Apple Silicon 和 Intel，要求 macOS 14+；返回 App 和来源自动显隐要求 macOS 15.2+。

当前使用临时签名，未经 Apple 公证，首次打开请参考[安装说明](https://github.com/laixintao/ontop/blob/main/README.zh-CN.md#安装)。附件包含 SHA-256 校验文件和 GitHub 构建来源证明。
