## Your reference, always in sight

OnTop's first public release: a tiny native macOS app for floating a live window preview above your work, while clicks and scrolling pass through to the window underneath.

### Highlights

- Hover for **Return to App**, **Stop**, source selection, and an opacity slider.
- Hide automatically while using the source app; restore in place when you switch away.
- Adjust opacity from **30–100%**. Move and resize proportionally with dedicated handles. Layout and opacity are remembered.
- Remove capture padding using frame metadata, without trimming legitimate black content.
- English and Simplified Chinese interfaces. No account, analytics, audio recording, saved frames, or network requests.

### Install

Download **OnTop-1.1.0-universal.dmg**, open it, and drag **OnTop** into **Applications**. Or unzip the ZIP. Both support Apple Silicon and Intel.

- **macOS 14+** for the preview and controls.
- **macOS 15.2+** for Return to App and automatic source-app hide/restore.
- Current installers are **ad-hoc signed, not Apple-notarized**. If the first launch is blocked, use **System Settings → Privacy & Security → Open Anyway** after trying to open the app. [Apple's instructions](https://support.apple.com/en-us/102445).

Checksums are in `SHA256SUMS`. GitHub build provenance can be verified with:

```bash
gh attestation verify OnTop-1.1.0-universal.dmg --repo laixintao/ontop
```

## 参考资料，始终在眼前

OnTop 首个公开版本：原生 macOS 实时置顶预览，鼠标点击和滚动穿透到下方窗口。

- 悬停显示 **返回 App**、**停止**、更换来源和不透明度控件。
- 使用来源 App 时收起，切走后原位恢复。

- 中英文界面，无账号、统计、音频采集、画面保存或网络请求。

下载 DMG 并把 OnTop 拖入「应用程序」，也可以解压 ZIP。通用包支持 Apple Silicon 和 Intel。预览功能要求 macOS 14+；返回与自动显隐要求 macOS 15.2+。

**当前未经过 Apple 公证**。如首次打开被拦截，先尝试打开，再前往「系统设置 → 隐私与安全性 → 仍要打开」。[Apple 的说明](https://support.apple.com/zh-cn/102445)。安装包附有 SHA-256 校验值和 GitHub 构建来源证明。
