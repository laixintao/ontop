## A grip that's easier to grab

The move grip now has a **44 × 44 point hit area**, up from 22 × 26, with a larger icon and a subtle background. You can drag from its padding as well as the icon. The toolbar stays the same height and remains above the picture.

The native drag test now starts at the edge of the enlarged grip to verify that the extra space accepts dragging without triggering adjacent buttons. English and Chinese control screenshots have been refreshed.

Quit OnTop before updating. With Homebrew:

```sh
brew update
brew upgrade --cask laixintao/tap/ontop
```

Or download **OnTop-1.3.1-universal.dmg** and drag OnTop into Applications. ZIP is also available. Both support Apple Silicon and Intel. Requires macOS 14+; Return to App and automatic source-app hiding require macOS 15.2+.

Builds are ad-hoc signed and not Apple-notarized. See the [installation instructions](https://github.com/laixintao/ontop#install). Downloads include `SHA256SUMS` and GitHub build provenance:

```sh
gh attestation verify OnTop-1.3.1-universal.dmg --repo laixintao/ontop
```

## 拖动更容易点中了

拖动手柄的可操作区域从 22 × 26 扩大到 **44 × 44 点**，面积约为原来的 3.4 倍。图标更大，增加浅色底，点到周围留白也能拖动。控制条高度不变，仍位于图片上方。

原生拖动测试改为从扩大后的手柄边缘开始，验证留白区域能拖动、不会触发相邻按钮；同步更新中英文控件截图。

先退出旧版，再运行上面的 Homebrew 升级命令，或下载安装包拖入「应用程序」替换。DMG / ZIP 均支持 Apple Silicon 和 Intel，要求 macOS 14+；返回 App 和来源自动显隐要求 macOS 15.2+。

当前使用临时签名，未经 Apple 公证，首次打开请参考[安装说明](https://github.com/laixintao/ontop/blob/main/README.zh-CN.md#安装)。附件包含 SHA-256 校验文件和 GitHub 构建来源证明。
