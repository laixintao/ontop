## Keep the whole picture in view

Hover controls now float **above the preview**, with the resize handle outside the bottom-right edge. The buttons no longer cover your reference, and hovering does not move or resize the picture.

### What's new

- **Hide** temporarily removes one preview without ending sharing. Restore it from the menu bar with **Show Preview** or **Show All Previews**.
- Hidden previews keep their source, position, size, and opacity. App switches and incoming frames keep them hidden until you restore them or explicitly choose another source.
- The toolbar stays reachable near screen edges. Moving the pointer across the gap between picture and controls keeps the buttons visible.
- Separate previews retain independent controls and visibility. Hiding one does not affect the others.
- Expanded native tests cover placement above the picture, screen edges and negative display coordinates, click-through in the former button areas, hover gaps, and hiding/restoring without stopping capture.

### Install

Quit the running OnTop, download **OnTop-1.3.0-universal.dmg**, and drag the new app into **Applications**. ZIP is also available. Both support Apple Silicon and Intel.

Requires **macOS 14+**. Return to App, automatic source-app hide/restore, and duplicate detection require **15.2+**. Restoring a manually hidden preview still respects source-app hiding: switch to another app to see it.

Current builds are **ad-hoc signed, not Apple-notarized**. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway** after attempting to open the app. [Apple's instructions](https://support.apple.com/en-us/102445).

Downloads include `SHA256SUMS` and GitHub build provenance:

```bash
gh attestation verify OnTop-1.3.0-universal.dmg --repo laixintao/ontop
```

## 按钮不遮图，预览随时隐藏

悬停控制条现在浮在**预览图片上方**，缩放手柄位于右下边缘外侧。画面完整可见，鼠标移入时不会改变图片位置或大小。

- 新增 **隐藏**：临时收起当前预览，保留共享，从菜单栏选择 **显示预览** 或 **显示全部预览** 即可恢复。
- 来源、位置、尺寸和透明度都会保留；切换 App 或收到新画面不会取消临时隐藏，直到手动恢复或明确更换来源。
- 屏幕边缘留出按钮空间，鼠标经过图片和控制条之间的间隙时不会闪退。
- 多个浮窗各自独立，隐藏一个不影响其他预览。
- 增加控件位置、屏幕边缘与负坐标屏幕、原按钮区域穿透、悬停间隙和保留共享的隐藏/恢复回归测试。

先退出旧版 OnTop，再下载通用 DMG 拖入「应用程序」替换；也提供 ZIP。支持 Apple Silicon 和 Intel，要求 macOS 14+，返回 App、来源自动显隐及去重要求 macOS 15.2+。恢复隐藏时仍遵循来源 App 自动显隐规则，切到其他 App 后显示。

**当前未经过 Apple 公证**。首次打开如被拦截，先尝试打开，再前往「系统设置 → 隐私与安全性 → 仍要打开」。[Apple 的说明](https://support.apple.com/zh-cn/102445)。附件提供 SHA-256 校验文件和 GitHub 构建来源证明。
